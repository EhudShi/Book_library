# הספרייה שלי

אתר סטטי (HTML בלבד, בלי build) של סיכומי ספרים בעברית. מתאים ל-Vercel כמו שהוא.

## הוספת ספר חדש
1. שמים את דף הסיכום ב-`books/<slug>.html` (מעתיקים ספר קיים כתבנית; הסגנון המשותף ב-`assets/book.css`).
2. מוסיפים שורה בראש `books.js` עם slug, כותרת, סופר, נושא, צבע ותקציר.
3. commit ו-push: Vercel מעלה גרסה חדשה לבד.

## עיצוב
העיצוב המשותף ב-`assets/theme.css` (צבעים וגופן) וב-`assets/book.css` (דף ספר).
`assets/book.js` בונה לבד בכל דף ספר את כרטיסי הרעיונות (מכל שורה עם `class="key"`) והופך את הצעדים המעשיים (`.todo li`) לרשימה לסימון. הסימונים נשמרים בדפדפן.
